# Cadora 프로토타입 v2.1 (클릭형 데모)

`docs/PRD.md`를 바탕으로 만든 브라우저용 클릭형 프로토타입이에요. 데이터는 모두 시뮬레이션이고, 빌드나 설치 없이 바로 열 수 있어요.

## 여는 법

- Windows 탐색기에서 `prototype/index.html`을 더블클릭해요. Chrome이나 Edge를 권장해요.
- WSL에서는 `cd prototype && explorer.exe index.html`을 실행해요.
- 외부 의존성이 없어요. 글꼴 Pretendard(SIL OFL 1.1)를 `fonts/`에 원본 그대로 넣어 두어 오프라인에서도 같은 글꼴로 보여요.

## 화면 구성

왼쪽 레일 맨 위가 워크스페이스 전환이고, 그 아래로 화면 4개가 있어요. 왼쪽 아래 아바타를 누르면 보는 사람(민수 노트북 A ↔ 지윤 노트북 B)이 바뀌어요. 워크스페이스·일정·과제는 **보는 사람별로 나뉘어서**, 개인 워크스페이스는 본인에게만 보여요.

| 화면 | 내용 | PRD |
|---|---|---|
| 작업공간 | 워크스페이스 목록(활성·백그라운드·잠자기)과 새로 만들기. 워크스페이스마다 전용 브라우저 세션(로그아웃해도 다른 곳은 그대로), 서버·터미널, 다운로드 폴더가 따로예요. 탭 줄에서 팀 공유 탭(핀)과 내 개인 탭(점선)이 구분돼요. | FR-01~05, FR-08, FR-19 |
| 팀 | 팀원과 에이전트를 그래프로 보여줘요. 작업 중인 노드는 빛나요. 충돌 가능성은 노란 선, 비슷한 작업은 보라 선이에요. 사이드바에는 팀원(팀장은 초대 가능), 오늘 타임라인, 남은 과제, 공유 범위 설정이 있어요. | FR-07, 09, 11~16, 18, 20 |
| 활동 | Cadora 알림·경고 피드예요. 충돌 경고는 "나에게만 보이는 알림"으로 해당 팀원에게만 가요. 대화는 아래 바에서 Discord로 이어져요. | FR-14, 15, 17 |
| 캘린더 | 주간 보기예요. 워크스페이스별 색, 마감 종일 칸, 현재 시각선이 있고, 일정을 누르면 남은 체크리스트가 열려요. 팀 과제 체크리스트는 팀원과 함께 봐요. | FR-20 (v1.2 제안) |

## PRD §12 시연 순서

오른쪽 위 **시연** 버튼으로 단계를 진행해요. 단계가 끝날 때마다 나오는 알림의 버튼으로 해당 화면으로 바로 갈 수 있어요.

1. **독립 환경**: 작업공간에서 캡스톤 팀플과 컴파일러 과제 3을 오가며 보여줘요.
   - 한쪽에서 로그아웃하거나 터미널에서 `stop`을 해도 다른 쪽은 그대로예요.
   - 같은 파일을 받아도 저장 폴더가 달라요.
2. **팀 환경 공유**: 시연 1단계에서 팀장 민수가 공유 탭을 추가해요. 지윤 작업공간 탭 줄에 `배포 대시보드 NEW`가 생기고, 지윤의 개인 탭은 그대로예요.
3. **AI 작업 시작**: 시연 2~3단계에서 지윤과 민수가 각자 Claude Code를 실행해요. 같은 `src/auth/`를 수정해서 두 사람에게 "비슷한 작업" 알림이 가요.
4. **사전 충돌 감지**: 시연 4단계에서 민수의 에이전트가 `schema.prisma`를 수정해요. **지윤 화면에만** 노란 충돌 선과 경고가 떠요. 민수 화면에는 회색 "지윤에게 알림 보냄"만 남아요.
5. **도구 역할 구분**: 시연 5단계에서 현우의 `docker-compose.yml`이 main에 반영돼 환경 변경 안내가 가요. 대화는 Discord, 편집은 "VS Code로 열기"로 넘겨요.

그 밖에 직접 해볼 수 있는 것:

- 팀 화면 터미널
  - `claude "작업 제목"`: 에이전트 실행
  - `edit package.json`: 분류 규칙 시험
  - `edit .env`: 민감 파일이라 전송 안 됨
- 그래프 노드를 눌러 에이전트 종료, 경고 근거 보기, 오탐 피드백
- 팀 사이드바 **초대** → 초대받은 사람 온보딩 미리보기
- 팀 사이드바 **공유 범위 설정**에서 작업 제목 공유 끄기

주소 바로가기 형식은 `index.html#<화면>/<단계>@<보는 사람>~<시각>`이에요. 화면 이름은 `home` · `team` · `activity` · `cal`이에요.

- `#team/4@jiyun`: 팀 화면, 4단계까지 진행, 지윤 시점
- `#home~14:30`: 현재 시각을 14:30으로 고정 (캘린더와 '오늘' 타임라인에만 적용되고, 활동·터미널의 시각은 실제 시각이에요)

## 여러 명이 실시간으로 (claude.ai 호스팅)

`hosted.html`을 claude.ai 아티팩트로 올려 두었어요. 처음 공개 범위는 올린 사람만 볼 수 있는 상태예요. 페이지의 **Share** 메뉴에서 팀원에게 공유해야 열려요.

- 처음 들어오면 **민수(팀장) · 지윤 · 현우** 중 한 자리를 골라요. 오른쪽 위에 지금 접속한 사람 수가, 팀 화면 팀원 목록에 자리별 접속자가 보여요.
- **함께 바뀌는 것**: 시연 단계, 에이전트 실행(팀 터미널의 `claude "…"`), 파일 변경(`edit …`), 경고 처리(무시 · 알려주기 · 피드백), 팀 과제 체크, 팀 공유 탭, 초대, 작업 제목 공유 설정이에요. 모두 공유 기록에 쌓여서, 접속한 모든 화면에 곧바로 반영돼요.
- **각자 브라우저에만 남는 것**: 로그인 세션, 작업공간 터미널·서버, 다운로드, 개인 탭, 개인 과제 체크, 보던 화면이에요. PRD의 개인 층이에요.
- **초기화**: 시연 메뉴의 **초기화 → 정말 초기화**는 접속한 모든 사람의 시연 기록을 처음으로 돌려요. 이전 기록은 지우지 않고 새 기록을 시작해요.
- **권한**:
  - 함께 조작하려면 claude.ai에 로그인하고 편집 권한이 있어야 해요. 같은 조직(Team·Enterprise) 구성원은 Contributor 이상, 이메일로 초대한 외부 사람은 Editor예요.
  - 보기 권한이나 공개 링크로 들어온 사람은 지켜보기만 해요. 화면에 "보기 전용"으로 표시돼요.
- 파일로 열거나 공유 데이터를 쓸 수 없으면 "혼자 보기"로 이 브라우저 안에서만 동작해요.

## 시뮬레이션과 실제의 경계

- **흉내 낸 것**: 프로세스, 브라우저, 다운로드, Claude Code Hooks, 팀 동기화 서버, Discord·VS Code 연동. 모두 메모리 안에서만 동작해요.
- **그대로 재사용할 수 있는 로직** (`sim.js`, DOM 없음): 변경 파일 분류, 감시 제외, Hook 원본을 최소 메타데이터로 정제, 비밀값 마스킹, 경고 규칙.

## 구조

```
prototype/
  index.html   진입점 (일반 스크립트 — 더블클릭으로도 열려요)
  hosted.html  claude.ai 아티팩트용 진입점 (문서 뼈대 없이 — 게시할 때 감싸져요)
  sim.js       시뮬레이션 코어 (v1 기반 + 시각·에이전트 ID를 밖에서 받도록 바꿈: 여러 기기가 같은 결과를 내도록)
  app.js       화면 + 공유 기록: 셸 · 작업공간 · 팀 · 활동 · 캘린더 · 모달 · 자리 · 접속자
  styles.css   그래파이트 + 청록 팔레트
  fonts/       PretendardVariable.woff2 + LICENSE.txt (원본 그대로)
  v1/          첫 번째 버전 (와이어프레임 6장 재현 + 이벤트 검사기)
```

- 루트에 `package.json`을 두지 않았어요. 루트에 생기면 CI가 Windows에서 `npm ci`와 lint, test 등을 돌리기 시작해요.
- 캘린더(FR-20)와 '팀 활동' 피드는 PRD v1.2 **제안**으로 추가돼 있어요. 리뷰 후 확정해야 해요. 일반 채팅은 PRD대로 범위 밖이라, 대화는 Discord로 연결해요.
