# 요구사항과 이슈 변경 이력

기존 요구사항 또는 GitHub 이슈의 내용·상태·담당자가 실제로 변경된 경우에만 기록한다. 단순한 문서 표현 수정·상세화나 새로운 내용의 추가만으로 요구사항·이슈가 바뀌지 않았다면 기록하지 않는다. 승인된 변경은 기준 문서에 반영한다. 각 기록에는 요구사항과 이슈가 각각 변경됐는지와 실제 반영 여부를 기재한다. 변경되지 않은 항목은 `변경 없음`, 미반영 항목은 그 이유와 함께 적는다. 이 규칙 도입 전 이력은 당시 작성 내용 그대로 보존한다.

## 기록 형식

```markdown
## YYYY-MM-DD — 변경 요약

- 관련 이슈: #번호 (없으면 없음)
- 요구사항 변경: 변경됨 / 변경 없음; 변경됐다면 번호·내용
- 이슈 변경: 변경됨 / 변경 없음 / 미반영; 변경됐다면 번호·내용, 미반영이면 이유
- 문서 반영: 반영됨 / 미반영; 파일명·항목 및 미반영 이유
- 변경 전: 기존 내용
- 변경 후: 승인된 내용
- 이유와 영향: 변경 배경과 영향을 받는 기능·팀
- 승인: 사용자 승인 여부
```
