# 요구사항과 계획 변경 이력

기존 요구사항이나 계획이 승인 후 변경된 경우에만 여기에 기록한다. 요구사항이나 계획을 바꾸지 않는 문서 표현 수정, 상세화 또는 새로운 내용의 추가는 기록하지 않는다. 기준 문서에는 승인된 변경 내용을 반영한다.

## 기록 형식

```markdown
## YYYY-MM-DD — 변경 요약

- 관련 이슈: #번호 (없으면 없음)
- 변경 문서: 파일명과 해당 항목
- 변경 전: 기존 내용
- 변경 후: 승인된 내용
- 이유와 영향: 변경 배경과 영향을 받는 기능·팀
- 승인: 사용자 승인 여부
```
